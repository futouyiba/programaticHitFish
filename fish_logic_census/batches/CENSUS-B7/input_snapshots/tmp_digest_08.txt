===== story_060.md :: FISH-R03｜荷包红鲤｜Wuyuan Red Carp｜Discrete Target + Resource Patch
--Reality Baseline--
荷包红鲤（Wuyuan red carp；地方鲤品系，通常按 *Cyprinus carpio* 基线处理）的物种级机制不能由红色表型单独推出。普通鲤资料支持底层杂食、植物残屑和底栖无脊椎资源；地方品系、养殖条件和投喂史可能改变响应，目前没有足够独立证据证明品系专属机制。[FishBase common carp](https://www.fishbase.se/summary/Cyprinus-carpio.html)
--Strategy Story--
先按普通鲤的底质与 Resource Patch 处理，再由离散目标进入 TargetFeeding。饵型、深度和停顿仅作设计推断；品系外观不购买独立 Mode。
--FCF Interpretation--
PrimaryEvaluand=Resource Patch + Discrete Target；ResponseChannels=TargetFeeding；SpatialPattern=Static Habitat + Slow Reorder。
--Lowest-Power Explanation--
P01 Discrete Target → TargetFeeding + Typed Context + P02 Resource Patch → Discrete Target → TargetFeeding 足以表达继承的鲤类机制，不新增 Wuyuan Mode。
--Competing Explanation--
差异可能来自投喂史、养殖环境、体型或选育，而非红色表型。
