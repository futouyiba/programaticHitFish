# RC4 flagship traces

These are compact acceptance traces. They specify semantic inputs and player
evidence; they do not introduce species×bait or season coefficients.

## Spawn Bass

```text
temperature/season progression
  -> LifecycleCommitment(mature, SPAWN_GUARD)
  -> stable SliceKey(bass_stock, mature, SPAWN_GUARD)
depth + substrate + structure + light
  -> OccupancyAllocationGrade(PRIME on SPAWN_SITE)
NEST_INTRUSION_ONSET
  -> Perception A -> DEFEND motive -> EntryOffer E
  -> finite entry -> Candidate -> THREAT_TRACK
INTRUSION_REMAINS_2S + INTRUSION_PERSISTS
  -> COMMIT_READY -> ContactIntent(BITE_REMOVE or allowed defensive type)
```

Player strategy: move away from the bed, change intrusion proximity, or alter
pause/persistence. Prey likeness is not required.

## Trout drift

```text
temperature + DO + flow
  -> occupancy and task context
player control + current
  -> ActualPresentation(drift quality, speed, stability)
light/turbidity/occlusion
  -> Perception A
prey-shaped drift cue
  -> FORAGE motive -> EntryOffer E -> Candidate
intercept demand
  -> deterministic Conversion (difficulty remains observable)
```

Player strategy: change position, drift line, speed, stability, or depth. The
same drag consequence must have one owner: Entry if physically impossible,
otherwise Conversion if merely difficult.

## Carp static bait

```text
groundbait deployment
  -> Resource Patch / cue
  -> future aggregation
  -> ARRIVAL of newly eligible finite mass
  -> FORAGE Entry
actual consumption
  -> future SatiationMixture
```

Player strategy: wait for new arrival mass, change presentation, or relocate.
Alternative Resource Competition is separate from Satiation, so fish presence
can rise while conversion falls without a hidden inverted-U coefficient.
