# Surface Coverage Audit｜C01–C15

审计目标：检查现有中文伪脚本与配置表是否覆盖 Group Routing、Bake、Response、Quality 四个执行面。

## 结论

现有具体化 bundle 主要按单一绑定面展开：C01/C02/C05 只有 Bake，C03/C04/C06–C13 主要只有 Response；Group Routing 与 Quality 多数只在全局说明、辅助样本或引用中出现，没有逐 Case 的完整投影。C14/C15 为边界案例，当前无生产绑定。

这不是语义结论，而是交付完整性缺口。现有 38 个 Binding 和 297 项检查不能证明四面完整，因为检查器只验证已登记 Binding 的引用与等义文本。

## 修订要求

后续修订必须给每个 Case 一个四面状态：`完整投影`、`复用既有模板`、`明确不适用` 或 `未闭合 TODO`。只有状态为完整投影时，才要求该面展开表格与中文脚本；复用则必须引用模板 ID 并列出差异。

本审计不改变任何 Frozen Story、Design Gate 或 Authority，也不自动决定 Config / DSL 选型。
